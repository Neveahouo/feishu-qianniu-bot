# purchase-limit-bot

飞书机器人自动修改淘宝/天猫千牛后台的**用户限购**规则。

场景：客服在群里反馈某商品客户想多买但被限购，机器人在千牛后台把该商品第一个限购时段的份数改成指定值；客户拍完后再改回默认 20 份。

## 工作流程

```
飞书群消息
   "解限购 642838749428 3"
        │
        ▼
   解析商品ID + 份数
        │
        ▼
   Playwright 操作千牛后台
   搜索商品ID → 打开限购设置 → 改第一个时段 → 点确定
        │
        ▼
   群里回复结果
     成功 → ✅
     商品在活动中 → ❌ 活动中暂无法解除
```

## 功能

- **解限购**：把第一个限购时段改到指定份数
- **恢复限购**：收到"已拍完"后改回默认 20 份
- **活动商品识别**：点确定后弹出「温馨提醒，限购无法生效」→ 判定为活动商品，回复无法解除
- **串行队列**：所有浏览器操作排队执行，避免并发冲突

## 环境要求

- Node.js >= 18
- 已安装 Google Chrome（使用系统 Chrome，不用自带 Chromium）
- 飞书自建应用，开启机器人能力，并已加入目标群
- 有千牛限购管理权限的淘宝/天猫卖家账号

## 配置步骤

### 1. 安装依赖

```bash
npm install
```

### 2. 填写配置

```bash
cp .env.example .env
```

编辑 `.env`：

| 变量 | 说明 |
| --- | --- |
| `FEISHU_APP_ID` / `FEISHU_APP_SECRET` | 飞书应用凭据 |
| `QIANNIU_USERNAME` / `QIANNIU_PASSWORD` | 可选，用于自动填登录表单 |
| `DEFAULT_LIMIT` | 恢复时的默认份数，默认 `20` |
| `HEADLESS` | 建议 `false`，需要窗口扫码登录 |

### 3. 配置飞书后台

进入 [飞书开放平台](https://open.feishu.cn)：

1. **添加应用能力** → 机器人
2. **权限管理** → 开通 `im:message`、`im:message:send_as_bot`
3. **事件与回调** → 订阅方式选择**「使用长连接接收事件/回调」**
4. **添加事件** → `im.message.receive_v1`
5. 发布版本，把机器人拉进目标群

### 4. 启动

```bash
node index.js
```

或 Windows 双击 `start.bat`。

首次运行会打开 Chrome 要求登录千牛。密码登录通常会触发滑块验证且自动化无法通过，请点**「扫码登录更便捷」**用手机淘宝/千牛扫码。登录态保存在 `chrome-user-data/`，后续启动一般无需重复登录。

### 5. 单独测试浏览器层

```bash
node test-qianniu.js 642838749428 3
```

## 群消息格式

| 意图 | 消息 |
| --- | --- |
| 解限购 | `解限购 <商品ID> <份数>` |
| 解限购（其他写法） | `限购 <商品ID> 改<份数>份` |
| 解限购（原自然语言） | 含商品链接（`...id=<商品ID>`）+ `<份数>份` + "限购" |
| 恢复 | `已拍完 <商品ID>` |
| 恢复（不带ID） | `已拍完`，自动取最近修改的商品 |

## 实现要点（改代码前必读）

1. **限购界面在 iframe 里**。内容渲染在 url 含 `purchaseLimitManagement` 的同源 iframe 中，主页面只有外壳，必须用 `page.frames()` 查找元素。
2. **登录表单在另一个 iframe**，name 为 `alibaba-login-box`，输入框是 `#fm-login-id` / `#fm-login-password`。
3. **商品ID搜索框的 placeholder 是「多个用逗号分隔」**，不是"商品ID"。
4. **份数输入框没有任何标识**：普通 `input[type="text"]`，id 和 placeholder 都为空，只能靠 value 是纯数字（如 `20`）来识别。它不是 `input[type=number]`。
5. **只改第一个时段**。面板里有 6 个时间段，改第一个（当前生效的）。
6. **失败判定靠文案**：点确定后出现含 `温馨提醒` / `限购无法生效` 的弹窗，说明商品在活动中、限购规则无法生效。
7. **必须做反检测**：用系统 Chrome + 持久化目录 + `--disable-blink-features=AutomationControlled` + 注入伪装脚本，否则滑块即使手动拖也会报错。

## 已知限制

- 淘宝页面改版会导致选择器失效，代码做了多重兜底但不保证永久可用
- 登录态会周期性过期，需要重新扫码
- 必须保持电脑不休眠、脚本常驻运行（这是本地脚本，不是云端服务）
- 不支持多店铺账号并行（一个账号一个浏览器目录）

## 使用须知

本项目操作的是**你自己的**卖家账号。请仅在自有账号上使用，并遵守淘宝/天猫服务条款和公司规定。凭据与登录态不会进仓库：`.env`、`qianniu_cookies.json`、`chrome-user-data/` 均已加入 `.gitignore`。
